# shreyascloud.tech

My portfolio. Black and white: a glyph portal over my name on the first screen, project clips, and two animated diagrams.

Vite + React + TypeScript + Tailwind v4, set up the shadcn way (`components.json`, components in `src/components/ui`).

```bash
npm install
npm run dev      # local
npm run build    # builds the diagrams, then outputs dist/
```

The diagrams for Container Sentinel and BPIP (Figs 3 and 4) are generated by `figures/container.mjs` and `figures/parking.mjs` with the anatomy kit in `figures/kit/` (MIT). `npm run figures` writes them to `public/figures/`; the build runs it, so those pages are not committed.
